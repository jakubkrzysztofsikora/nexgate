# Code of Conduct

We are committed to a welcoming, respectful community. Be constructive, assume
good intent, respect differing experience levels, and do not harass, threaten,
or disclose another person's private information.

Report conduct concerns privately through a GitHub Security Advisory. Include
only the information needed to assess the conduct concern. Maintainers may
remove content or participation that violates this policy. Retaliation against
reporters is not tolerated.
